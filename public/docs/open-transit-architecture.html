Open Transit Architecture: Engineering Sub-100ms GTFS Timetables

Published by Shivrajsinh Zala • Reference Implementations: Headway & Stopwatch

1. Production Systems Overview

This technical guide documents the open-source architecture powering two high-scale public transportation systems:

Headway Transit Engine (https://headway.shivrajsinh.in)

The core GTFS processing and graph analysis engine. Headway ingests multi-gigabyte open transit datasets, flattens relational service calendars, pre-indexes corridor stop matrices, and generates high-frequency headway departure statistics.

Stopwatch Public Bus Timetables (https://transit.shivrajsinh.in)

The consumer-facing public timetable directory. Stopwatch serves comprehensive bus, tram, and rail timetables across 120+ transit agencies in 6 countries. Built with Astro SSG to deliver sub-100ms page loads with zero runtime client-side JavaScript.

4. Programmatic Indexing & Crawl Budget Optimization

Managing over 200,000 public transit routes and stop URLs across Headway and Stopwatch requires strict sitemap partitioning and instant indexing:

  • Hierarchical Sitemaps: Capped at 45,000 URLs per sub-sitemap under a root sitemap-index.xml.
  • IndexNow Webhooks: Modified schedules are submitted via automated API batches directly to search engines.
  • Deterministic Canonicalization: Parameterized filters and direction variations enforce canonical tags to prevent duplicate indexing.
